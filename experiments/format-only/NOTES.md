# Did it only change the format?

Date: 2026-09-25. Asking an AI to reformat a text often gets the text quietly
rewritten. The question here is narrow: how much of "the words stayed the
same" can a machine check, and where does checking stop?

The question came from a text the owner shared, which is not included here.

## What it checks

`format_only.py source output` compares both texts as word sequences after
removing formatting only:
- whitespace and line breaks;
- markdown line markers (`#`, `>`, bullets, numbering);
- emphasis markers at word edges (`**`, `*`, `__`, `_`, `` ` ``).

Everything else counts as a change: words, their order, case, punctuation,
symbols, emoji. An underscore inside a word stays part of the word.

## Results

- 11 tests (`python3 -B -m unittest`) pass. Eight show what is caught, or
  correctly passed as format. Three document blind spots.
- All tests passed on the first run, so I broke the checker five ways:
  - ignoring case;
  - stripping punctuation;
  - removing every underscore;
  - ignoring word order;
  - keeping markdown markers.

  The tests caught all five. [V]
- **Real use.** Source: the pull-request text I sent for #4, taken verbatim
  from the session transcript. Output: the text GitHub stored. The checker
  found exactly one change: the footer the platform appended
  (`INSERT --- Generated by [Claude Code](…)`). That confirms mechanically what
  `../github-witness/NOTES.md` recorded by eye. [V]
- **My own additions.** I had said the test examples were made up. Checked
  against the shared text, one token in them came from it. It was replaced
  before the push. [V] A word-overlap check, skipping words already in this
  repository, then found only common words. It cannot see where an idea came
  from. A new `CLAUDE.md` question paraphrased a rule from the shared text, in
  words this repository already used. A control run confirmed the check would
  not have flagged it. [V] I noticed it by reading, and rewrote the question in
  this repository's own terms.

## Where checking stops

Blind spots, each kept as a passing test:
- **Emphasis added or removed passes as format**, although it can shift the
  weight of a sentence.
- **Line breaks do not count**, although in a poem or a song they carry rhythm.
- **A `*` used as a symbol is stripped** like emphasis.

The larger limit is not in the code. **Words can be anchored to a source;
meaning cannot.** This can prove that a "reformatted" text still says the same
words in the same order. It cannot prove that a summary, an interpretation or a
new framing is faithful. That judgement stays with a human, which is where the
rest of this repository keeps ending up too.
